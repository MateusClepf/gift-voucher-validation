About This Project

This is a demo of a secure voucher validation system with Cloudflare Turnstile protection.

API Endpoints

Backend API URL: https://shop-test-api.requestlab.net/validate-voucher

Note: The frontend sends requests to this API URL, but they are intercepted by a Cloudflare Worker that validates the Turnstile token before forwarding to the backend.

Project Structure

  • Frontend: HTML, CSS, and JavaScript (this page)
  • Cloudflare Worker: Validates Turnstile tokens and proxies requests
  • Backend API: Validates voucher codes against a database
